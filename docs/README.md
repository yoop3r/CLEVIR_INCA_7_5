# Docs

## dotnet10-upgrade-assessment.json

Assessment report produced by the .NET Upgrade Assistant during the
.NET Framework 4.8 → .NET 10 migration (branch `upgrade-dotnet-10`,
generated 2026-07-02).

Originally written by Visual Studio to `.vs\upgrade\assessment\63fdb4e1.json`.
The `.vs` folder is a regenerable IDE cache that is git-ignored and gets deleted
whenever IDE state needs clearing, so this copy was moved here to preserve the
record of the upgrade.

Reference material only - nothing in the build consumes this file.
